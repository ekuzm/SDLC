## Воспроизведение графики и проверок

```sh
python3 tools/build_model.py
python3 tools/render_diagrams.py
node tools/render_diagrams.cjs
python3 tools/build_mockups.py
node tools/render_mockups.cjs
python3 tools/check_artifacts.py
```

Python 3 использует стандартную библиотеку для приведённых скриптов. Для PNG нужны Node.js и пакеты `sharp` и `playwright`, а также браузер Chromium для Playwright. Если используются предустановленные пакеты, укажите их каталог в `NODE_PATH`; браузер можно выбрать через `PLAYWRIGHT_BROWSERS_PATH`. Проверка модели описана в [srs/sysml/README.md](srs/sysml/README.md).

Кафедральные шаблоны SRS, SDD и ADR сохранены. Архитектура, выбор СУБД и работающий сервер будут разработаны в следующих лабораторных.
