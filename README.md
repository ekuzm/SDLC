# Баланс

Веб-приложение на Go для анализа и прогнозирования личного бюджета. Учебный проект по дисциплине «Жизненный цикл разработки программного обеспечения», БГУИР. Автор: Кузьменков Егор Валентинович, группа 450503.

## Запуск

Нужен Go 1.26 или новее. Внешних Go-зависимостей, Node.js и отдельной СУБД для запуска не требуется.

```sh
go run ./cmd/balance
```

Откройте **http://127.0.0.1:8080**, зарегистрируйтесь (пароль от 12 символов) и укажите начальный остаток и дату начала в разделе «Настройки». Категории доходов и расходов создаются автоматически. Данные сохраняются в data/balance.json; перезапуск сохраняет бюджет и завершает сеансы.

```sh
# Альтернативный запуск в Docker
docker compose up --build -d
# Сборка, проверки
make build
make check
```

[Конфигурация, HTTPS, резервное копирование и восстановление](docs/implementation.md#эксплуатация).

## Возможности

- Регистрация, вход, выход, отдельный бюджет каждого пользователя в BYN.
- Начальный остаток, доходы и расходы; редактирование, подтверждение удаления, фильтры и страницы списка.
- Категории, архив, месячные лимиты и предупреждения о перерасходе.
- Ежемесячные доходы и расходы, короткие месяцы, просрочка, пропуск, перенос и исполнение через новую или существующую операцию.
- Аналитика категорий и сравнение любых двух периодов; прогноз остатка к концу месяца и расходов следующего.
- Объяснение формул, недостаточная история, отрицательный остаток; точные расчёты в копейках.
- Атомарное файловое хранилище, защита форм и сеансов, ограничение попыток входа, суточные резервные копии.

Банковских подключений, нескольких счетов, других валют и машинного обучения в первой версии нет.

Сервер рассчитан на один процесс и локальное хранилище Linux/macOS. Для HTTPS-развёртывания включите BALANCE_COOKIE_SECURE=true; для встроенного TLS достаточно указать BALANCE_TLS_CERT и BALANCE_TLS_KEY. Локальный HTTP по умолчанию слушает только 127.0.0.1. Проверены Chromium, Firefox и нагрузка в Linux-контейнере 2 CPU / 2 GiB. Проверка реального HTTPS-развёртывания и оставшиеся ограничения перечислены в протоколе.
