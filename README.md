# Кредит на жильё

**Автор:** Егор Кузьменков

**Дисциплина:** «Жизненный цикл разработки программного обеспечения»

**Вариант:** 19

## Описание проекта

«Кредит на жильё» — настольное приложение на языке Go с графическим интерфейсом на базе Fyne. Проект предназначен для расчёта платежей по жилищному кредиту и оценки общей финансовой нагрузки на заёмщика.

Пользователь вводит сумму кредита, годовую процентную ставку и срок кредитования в месяцах. На основе этих данных приложение рассчитывает:

- ежемесячный аннуитетный платёж;
- общую сумму выплат банку;
- сумму переплаты;
- коэффициент и процент переплаты.

Приложение проверяет корректность введённых данных и выводит сообщения об ошибках. Последние успешно введённые параметры сохраняются в модели и восстанавливаются при повторном открытии окна ввода.
