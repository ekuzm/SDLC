# Баланс

Система анализа и прогнозирования личного бюджета. Учебный веб-проект на Go по дисциплине «Жизненный цикл разработки программного обеспечения», БГУИР.

Автор: Кузьменков Е. В., группа 450503.

## Лабораторная работа №3

Первая версия продукта: единый бюджет в BYN, ручной учёт доходов и расходов, категории и месячные лимиты, регулярные платежи, анализ расходов, прогноз остатка к концу месяца и расходов следующего месяца.

- [SRS 0.3](srs/srs.md) — 37 требований, критерии приёмки, матрица верификации и приложения.
- [Модели SysML v2](srs/sysml/README.md) — требования, контекст, варианты использования и шесть экранов.
- [Графические материалы PNG](srs/images/) — восемь изображений, полученных из моделей.
- [Сценарии проверки](srs/verification/scenarios.md) и [результаты проверки документации](srs/verification/document-checks.md).
- [Отчёт DOCX](reports/lab3/Отчёт_ЛР3_Баланс.docx).

## Построение графики и проверка

При установленном и запущенном Docker:

```sh
sh srs/sysml/tools/render-all.sh
python3 tools/check_artifacts.py
```

Используются SysML v2 Pilot Implementation 0.62.0, Java 21 и Graphviz. PNG сохранены в Git: для просмотра запуск Docker не требуется. Подробнее — в [инструкции](srs/sysml/README.md).

Комплект относится к этапу разработки требований. Архитектурные решения и реализация приложения относятся к следующим этапам. Шаблоны SRS, SDD и ADR сохранены.
