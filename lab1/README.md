# Кредит на жильё — лабораторная работа №1

Desktop-приложение на Go для варианта 19. Пользователь вводит сумму, годовую процентную ставку и срок кредита, после чего получает:

- аннуитетный ежемесячный платёж;
- общую сумму выплат банку;
- сумму переплаты;
- коэффициент и процент переплаты.

Срок кредита вводится только в месяцах. Последние успешно введённые параметры сохраняются в модели и автоматически восстанавливаются при повторном открытии окна ввода. Некорректные значения отображаются отдельным сообщением об ошибке.

## Архитектура MVC

Проект использует MVC с активной моделью:

```text
View -- действия пользователя --> Controller -- проверенные данные --> Model
  ^                                                                  |
  |---------------- уведомление ModelChanged -------------------------|
```

- `internal/model` — состояние и бизнес-логика аннуитетного кредита; модель уведомляет наблюдателей после изменения.
- `internal/controller` — преобразование строк формы в типизированные значения и вызов модели.
- `internal/view` — окна Fyne в минималистичной графитовой палитре, форматирование результата и показ ошибок.
- `internal/apperror` — глобальные типизированные ошибки, распознаваемые через `errors.Is`.
- `internal/app` — сборка зависимостей без бизнес-логики.

Месячный платёж рассчитывается по формуле:

```text
A = P × r × (1 + r)^n / ((1 + r)^n − 1)
```

где `P` — сумма кредита, `r` — месячная ставка, `n` — срок в месяцах. Для нулевой ставки используется `A = P / n`.

## Запуск

Требуются Go 1.25 и системные зависимости Fyne.

```bash
go run ./cmd/mortgage-calculator
```

Сборка исполняемого файла:

```bash
go build -o bin/mortgage-calculator ./cmd/mortgage-calculator
```
