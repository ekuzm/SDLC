# Иллюстрации отчёта «Баланс»

Диаграммы сохраняют оформление образца отчёта: стандартные UML-участники и варианты использования, деревья требований с серо-голубыми узлами и UML-модель предметной области. Пять экранов раздела 3.5 выполнены в отдельном дизайне: верхняя навигация, светлый тёплый фон, зелёные акценты, крупные показатели и круговые диаграммы. Данные и сценарии сохранены.

Макеты являются проектными иллюстрациями, а не снимками работающего приложения. Два нижних блока экрана операций иллюстрируют отдельные состояния пустой выборки и подтверждения удаления. Данные относятся к условному примеру на конец дня 26.10.2026. Начальный остаток 500,00 BYN и фактическое движение средств дают остаток 1 000,00 BYN; исторические месяцы примера имеют нулевое суммарное изменение остатка. Расходы 920,00 BYN за 92 дня дают среднее 10,00 BYN в день. Прогнозы составляют 850,00 BYN и 400,00 BYN.

Состав требований берётся из [единого реестра](../../../srs/data/requirements.json). UML-модель показывает ключевые связи словаря данных; поля идентификаторов не предписывают конкретную СУБД. Все сохраняемые объекты принадлежат бюджету непосредственно или через категорию/правило. Прогноз — вычисляемые данные.

## Повторное построение

Нужны Python 3, Node.js и пакет sharp (при построении использовалась версия 0.35.5); используйте окружение с поддержкой кириллицы (Arial или DejaVu Sans). Из корня репозитория:

```sh
python3 tools/build_report_figures.py
node tools/build_report_png.cjs
python3 tools/check_artifacts.py
```

При отсутствии sharp его можно установить в отдельный временный каталог и указать путь к модулям через `NODE_PATH`. SVG редактируются любым совместимым векторным редактором; для воспроизводимости изменения следует переносить в [генератор](../../../tools/build_report_figures.py). Растеризация выполняется [отдельным инструментом](../../../tools/build_report_png.cjs), без браузера и HTML.

[Формальные модели SysML v2 и их восемь представлений Pilot](../../../srs/sysml/README.md) сохранены отдельно. Иллюстрации отчёта не выдаются за прямой экспорт Pilot.
