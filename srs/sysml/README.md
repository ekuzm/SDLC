# Модель SysML v2 проекта Баланс

`balance.sysml` содержит 37 требований, 37 связей satisfy, шесть вариантов использования, модель экранов и переходов и семь определений предметной области.

Модель использует текстовую нотацию SysML v2: `part def`, `item def`, `requirement`, `subject`, `actor`, `use case def`, `satisfy`, `state`, `transition` и `dependency`. Основные конструкции сверены с [официальными примерами](https://github.com/Systems-Modeling/SysML-v2-Release) и [спецификацией OMG](https://www.omg.org/spec/SysML/2.0/).

## Назначение представлений

SVG в `views` и соответствующие PNG в `../img` являются читаемыми проекциями элементов исходной модели, подготовленными для отчёта. Они генерируются локальным инструментом, а не экспортом коммерческого SysML-редактора. Идентификаторы и названия требований извлекаются из `.sysml`; макеты HTML визуализируют экраны, заданные в пакете UserInterface. Связь модели экранов с HTML задаётся атрибутом mockup.

Группы требований соответствуют пакетам модели. На диаграммах показываются имена и короткие названия; полные формулировки и критерии находятся в SRS. Связи satisfy — утверждения проектного назначения системы на стадии требований; успешное тестирование реализации ими не подтверждается.

## Воспроизведение

Из корня репозитория:

```sh
python3 tools/build_model.py
python3 tools/render_diagrams.py
node tools/render_diagrams.cjs
node tools/check_sysml.cjs /path/to/ellidiss.sysml-ellidiss-1.0.0/sysml-extension
python3 tools/check_artifacts.py
```

Для PNG требуется пакет Node.js `sharp`. Проверка синтаксиса использует установленный парсер Ellidiss 1.0.0; путь задаётся аргументом, личные пути пользователя в скрипт не включены. Проверяются полный разбор текста и отсутствие синтаксической ошибки. Семантическая проверка типов и разрешения всех ссылок этим скриптом не выполняется. Согласованность ID, формулировок и количества связей проверяет `check_artifacts.py`.

Изображения доступны непосредственно в репозитории и не требуют запуска инструментов для просмотра.
